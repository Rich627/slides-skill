# Storyline skeletons by purpose

Pick one, then rewrite every title as a full-sentence takeaway. Slide counts are for
10–15 minutes; scale with talk time (≈ 1 slide per minute).

## Class assignment / homework report (6–10 slides)
cover → bullets `numbered` (the questions or scope) → chart or image (key finding 1) →
cards or table (findings 2–3) → quote (mechanism or key concept) → cards (implications
/ limitations) → references → closing ("Questions?")
Theme: `forest`, `sky` or `mono`. Kicker = course code. Cite every borrowed figure.

## Pitch deck (10–13 slides)
cover (with product image) → section or quote (the problem) → stats (problem size) →
flow (how the product works) → image (product) → chart (unit economics / growth) →
cards (traction) → table (competition) → timeline (roadmap) → bullets two columns (team) →
next (the ask, use of funds) → closing (contact)
Theme: `navy`, `coral` or `violet`. Titles carry the numbers ("Three pilots, 11,000 shipments").

## Project / team update (8–12 slides)
cover (milestone) → cards (what we do) → flow (how it works) → table (feedback → change →
effect) → options or stats (evidence) → cards `01` + divider (decisions needed) → next →
references → appendix (flow with branches, table)
Theme: `gold` (or the org's colour). Footer `source` on every claim slide; caveats visible.

## Lecture / teaching (12–20 slides)
cover → bullets numbered (learning goals) → section per topic, each: quote or image
(concept) → flow or timeline (process / history) → chart (data) → cards (examples) →
bullets (recap) → references → closing (exercise or reading)
Theme: `sky` or `mono`. Keep body text at 3 lines; the spoken words go in `notes`.

## Workshop / training (8–15 slides)
cover → cards (agenda, `numbering: "01"`) → section per module: flow (steps) → image
(demo) → table (do / don't) → options (scenario + choices) → next (what to try this week)
→ closing

## Portfolio / case study (8–12 slides)
cover (hero image) → quote (brief) → stats (constraints) → image slides (process, side
alternating) → flow (approach) → chart or stats (outcome) → cards (learnings) → closing

## Status / review for executives (5–8 slides)
cover → stats (headline numbers + caveat banner) → table (risks: item / impact / owner) →
timeline (dates, `state` done/now/next) → next (decisions needed) → references
